# GlowSkin — Landing Page

A visually polished static landing page for **GlowSkin**, a fictional skincare brand.

This project was created as part of the **Oasis Infobyte Web Development & Designing Internship — Level 1, Task 1**.

---

## Project Objective

The objective of this task is to build a visually polished static landing page
for a product, service, or brand of choice.

This project focuses on developing foundational **HTML and CSS layout skills**
through a responsive and visually consistent landing page.

---

## Tech Stack

- HTML5
- CSS3

> JavaScript is not required for this task.

---

## Features

The GlowSkin landing page includes the required features from the task:

- Sticky navigation bar
- Multiple navigation links
- Hero section
- Main headline
- Supporting subheadline
- Call-to-action button
- Multiple content sections
- Footer
- Placeholder contact/social links
- Consistent colour palette
- Responsive layout
- CSS Flexbox/Grid
- Proper padding and margins
- Box-sizing
- Clean and readable typography
- CSS animations and hover effects

---

## Website Sections

### 1. Navigation Bar

A sticky navigation bar is provided at the top of the page with links to
different sections of the website.

### 2. Hero Section

The hero section introduces the GlowSkin brand with:

- Headline
- Subheadline
- Call-to-action button

### 3. Features Section

The features section presents the main benefits of the GlowSkin product
using individual content cards.

### 4. About Section

The About section provides information about the GlowSkin brand and its
purpose.

### 5. Contact / Call-to-Action Section

This section encourages visitors to connect with the brand and take action.

### 6. Footer

The footer contains placeholder contact and social links.

---

## Responsive Design

The landing page is designed to remain usable across different screen sizes.

Responsive techniques used in the project include:

- CSS Flexbox
- CSS Grid
- Media queries
- Flexible widths
- Responsive spacing
- Box-sizing

The layout is designed so that elements do not overlap or break on smaller
screen widths.

---

## Design

The website uses a consistent colour palette throughout all sections.

The design focuses on:

- Clean spacing
- Readable typography
- Consistent visual hierarchy
- Rounded cards
- Soft skincare-inspired colours
- Simple and polished layout

---

## Animations

CSS animations and transitions are used to improve the visual experience.

The project includes:

- Hero section animation
- Navigation link hover effect
- Button hover effect
- Card hover effect
- Logo hover effect

These animations are implemented using CSS.
